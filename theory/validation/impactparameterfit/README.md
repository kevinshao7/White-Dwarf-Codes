# Impact-Parameter Cutoff Validation

This directory studies how the finite impact-parameter cutoff `bmax/aH`
changes the drag model in `theory/dragbase2.py`.

The figure formerly named `impact_parameter_fit.png` is generated by
`fit_bmax_to_lammps.py`. Its clearer output name is now:

```text
bmax_fit_lammps_overlay.png
```

For scripts that sweep `bmax/aH`, `--rhores` and `--dphires` are interpreted as
the impact-bin and scattering-angle resolutions at `bmax/aH = 1`. The
finite-launch impact grid is equal-area, so maintaining a consistent physical
impact-bin width requires `rhores_effective = ceil(rhores * (bmax/aH)^2)`.
The scattering-angle quadrature uses `dphires_effective = ceil(dphires *
bmax/aH)`.

## Main Scripts

- `fit_bmax_to_lammps.py`
  Fits one parameter, `bmax/aH`, for each condition and plots the LAMMPS data,
  selected fit points, best-fit theory curves, and +/- 10% cutoff bands.

- `compare_fixed_bmax_ah1.py`
  Runs the same model without optimization, using fixed `bmax/aH = 1` for all
  conditions.

- `sweep_bmax_shape_asymptotic.py`
  Sweeps selected `bmax/aH` values and velocities using the older asymptotic
  launch convention from `common.py`.

- `sweep_bmax_shape_finite_launch.py`
  Runs the same sweep using `commonfinite.py`, where particles are launched
  from a finite radius and angular momentum is computed self-consistently as
  `L = mu r_start v_start sin(theta)`.

- `plot_bmax_fit_trends.py`
  Replots the fitted cutoff from `bmax_fit_summary.csv` in several
  normalizations: `aH`, ion screening length, Yukawa screening length, and
  electron Debye length.

- `plot_closest_approach_by_bmax.py`
  Sweeps `bmax/aH` and plots the point of closest approach, `rmin`, for
  selected retained impact-parameter bins inside the drag integral.

- `plot_condition3_impact_bin_contributions.py`
  Decomposes the condition 3 finite-launch drag integral into
  launch-impact-parameter bins.

- `bmax_resolution_scaling.py`
  Shared helper for scaling `rhores`, `ures`, and `dphires` as `bmax/aH`
  changes.

## Main Outputs

- `bmax_fit_lammps_overlay.png`
  Main fit plot comparing LAMMPS data to fitted theory curves.

- `bmax_fit_summary.csv`
  Best-fit cutoff and derived length-scale normalizations.

- `bmax_fit_lammps_predictions.csv`
  Model/data comparison at the selected fit points.

- `bmax_fit_model_curves.csv`
  Smooth model curves at the fitted cutoffs.

- `bmax_fit_trends.png`, `bmax_fit_trends.csv`
  Trend plots/tables derived from `bmax_fit_summary.csv`.

- `fixed_bmax_ah1_comparison.png`
  Fixed-cutoff comparison for `bmax/aH = 1`.

- `fixed_bmax_ah1_summary.csv`, `fixed_bmax_ah1_lammps_predictions.csv`,
  `fixed_bmax_ah1_model_curves.csv`
  Tables from the fixed-cutoff comparison.

- `bmax_shape_sweep_asymptotic_curves.csv`
  Drag values from the explicit `bmax/aH` sweep in
  `sweep_bmax_shape_asymptotic.py`.

- `bmax_shape_sweep_asymptotic_condition_1.png`,
  `bmax_shape_sweep_asymptotic_condition_3.png`
  Per-condition plots from the asymptotic launch sweep.

- `closest_approach_by_bmax.csv`, `closest_approach_by_bmax.png`
  Closest-approach diagnostics from `plot_closest_approach_by_bmax.py`.

- `condition3_impact_bin_contributions.csv`,
  `condition3_impact_bin_contributions.png`
  Per-bin drag-force contributions from
  `plot_condition3_impact_bin_contributions.py`.
